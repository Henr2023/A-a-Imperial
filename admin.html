Conexão para salvar

Para salvar o estoque e enviar fotos, o painel precisa de uma chave do GitHub. Você faz isso uma vez só em cada aparelho:

1. Criar minha chave no GitHub ↗

  1. O GitHub pode pedir para confirmar por e-mail. Confirme e volte para a tela da chave.
  2. Em Repository access escolha Only select repositories e marque A-a-Imperial.
  3. Em Permissions → Repository permissions → Contents deixe Read and write (já deve vir marcado).
  4. Vá até o fim, toque em Generate token e copie a chave (começa com github_pat_).
  5. Volte aqui, cole no campo abaixo e toque em Guardar.
